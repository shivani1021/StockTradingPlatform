Stock Trading Platform (Zerodha Clone)
A full-stack stock trading application consisting of a main frontend for users,
a specialized dashboard for trading data, and a robust backend.

📂 Project Structure
The repository is organized into three main modules:

backend/: Node.js/Express server handling data and API logic.

frontend/: The primary user interface for the trading platform.

dashboard/: A dedicated interface for managing portfolios and market data.

🛠️ Tech Stack
Frontend & Dashboard: React.js / Vite

Backend: Node.js, Express

Database: MongoDB (Mongoose)

Version Control: Git & GitHub


🚀 Getting Started
1. Clone the repository
Bash
git clone https://github.com/shivani1021/StockTradingPlatform.git
cd "Zerodha Clone"
2. Setup Backend
Bash
cd backend
npm install
npm start
3. Setup Frontend
Bash
cd ../frontend
npm install
npm run dev
4. Setup Dashboard
Bash
cd ../dashboard
npm install
npm run dev
